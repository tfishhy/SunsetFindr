# SunsetFindr 🌅


Sunset Tracker is a web application that analyzes and predicts the quality of sunsets based on your location. Using weather and atmospheric data, it helps users find the best places and times to experience stunning sunsets all displayed on an interactive map.

# Features
Interactive map to explore sunset conditions by location
Sunset quality scoring (based on clouds, humidity, visibility, etc.)
Location-based predictions
Real-time and future sunset forecasts
Visual indicators for “good”, “average”, or “amazing” sunsets

# Tech Stack
Frontend: React + Leaflet
Backend: Node.js
APIs: weather API like OpenWeather etc tbd
